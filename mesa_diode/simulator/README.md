# Симулятор мезы Ge/Si (ВАХ и ВФХ)

Интерактивный GUI: задаёте геометрию мезы и электрофизические параметры —
получаете расчётные ВАХ и ВФХ с возможностью наложить экспериментальные
точки для сравнения. В отличие от остальной части `mesa_diode`, работает
без `MESA_DATA_DIR` — это прямая модель, а не подгонка под данные образца.

## Запуск из исходников

Из корня репозитория, после обычной установки (см. README.md репозитория):

```bash
python scripts/run_simulator.py
```

На Linux, если увидите `ModuleNotFoundError: No module named 'tkinter'`,
доустановите системный пакет (в venv не ставится через pip):

```bash
sudo apt install python3-tk        # Debian/Ubuntu
sudo dnf install python3-tkinter   # Fedora
```

На Windows и macOS Tkinter уже входит в стандартную поставку Python.

## Сборка в отдельный .exe (Windows)

Готовый `.exe` не требует Python на машине, где он запускается — его можно
переносить и запускать отдельно от остального кода репозитория.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-build.txt

pyinstaller packaging\mesa_simulator.spec
```

Файл появится в `dist\MesaSimulator.exe`. Скопируйте его куда угодно —
дальше он запускается двойным щелчком.

Быстрая альтернатива без spec-файла (тот же результат одной командой):

```bat
pyinstaller --onefile --windowed --name MesaSimulator scripts\run_simulator.py
```

### Предупреждение SmartScreen

При первом запуске нового `.exe` Windows Defender SmartScreen может
показать «Windows защитила ваш компьютер» — это стандартная реакция на
неподписанные `.exe`, а не признак вредоносности. Чтобы продолжить:
**«Подробнее» → «Выполнить в любом случае»**.

## Работа с приложением

Восемь полей внизу окна — параметры мезы: **D** (диаметр, мкм), **h**
(глубина, мкм, только для схемы), **N_D** (доноры в Si, см⁻³), **N_A**
(акцепторы в Ge, см⁻³), **T** (К), **R_s** и **R_sh** (Ом), **n₂**
(коэффициент неидеальности рекомбинационного тока). Числа вида `1e17`
понимаются как 10¹⁷. После изменения значений нажмите **«Рассчитать»**
(или Enter в любом поле).

**Загрузка экспериментальных данных** (кнопки вверху или меню «Данные»):
можно выбрать сразу несколько файлов в одном диалоге — до 5 наборов на
каждый график (ВАХ и ВФХ считаются раздельно). Каждый набор получает свой
маркер и цвет, в легенде — имя файла. При попытке загрузить больше 5
лишние файлы не загружаются, появится предупреждение — уберите часть
данных через «Очистить эксперим. данные» и загрузите заново.

Формат файла — два числовых столбца (`.csv`/`.txt`/`.dat`, разделитель
определяется автоматически). Единицы — СИ: для ВАХ вольты и амперы, для
ВФХ вольты и фарады. Заголовок в первой строке пропускается автоматически.

**Формулы и параметры** (кнопка вверху или меню «Справка») — отдельное
окно с полным перечнем формул модели и единиц измерения параметров.

График ВФХ строится с логарифмической осью ёмкости — так резкость
p-n(гетеро)перехода видна по наклону прямой (см. окно «Формулы и
параметры», раздел 6).
