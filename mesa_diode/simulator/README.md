# Симулятор мезадиода Ge (ВАХ, ВФХ, J–V)

Интерактивный GUI: задаёте параметры структуры мезадиода — получаете
расчётные ВАХ, ВФХ и плотность тока и сравниваете их с экспериментом на
тех же графиках. Модель — гомопереход Ge с двумя сценариями положения
перехода; формулы, источники и вычисляемые величины — в окне «Формулы и
параметры».

## Запуск из исходников

Из корня репозитория, после обычной установки (см. README.md репозитория):

```bash
python scripts/run_simulator.py
```

На Linux, если увидите `ModuleNotFoundError: No module named 'tkinter'`,
доустановите системный пакет (в venv не ставится через pip):

```bash
sudo apt install python3-tk        # Debian/Ubuntu
sudo dnf install python3-tkinter   # Fedora
```

На Windows и macOS Tkinter уже входит в стандартную поставку Python.

## Сборка в отдельный .exe (Windows)

Готовый `.exe` не требует Python на машине, где он запускается — его можно
переносить и запускать отдельно от остального кода репозитория.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-build.txt

pyinstaller packaging\mesa_simulator.spec
```

Файл появится в `dist\MesaSimulator.exe`. Скопируйте его куда угодно —
дальше он запускается двойным щелчком.

Быстрая альтернатива без spec-файла (тот же результат одной командой):

```bat
pyinstaller --onefile --windowed --name MesaSimulator scripts\run_simulator.py
```

### Предупреждение SmartScreen

При первом запуске нового `.exe` Windows Defender SmartScreen может
показать «Windows защитила ваш компьютер» — это стандартная реакция на
неподписанные `.exe`, а не признак вредоносности. Чтобы продолжить:
**«Подробнее» → «Выполнить в любом случае»**.

## Работа с приложением

**Основное окно** (с версии 3.6) читается слева направо, как идёт работа;
компоновка одинакова во всех трёх режимах:

- **сверху — режим** (кнопки «1. Базовая», «2. Расширенная», «3. Подгонка»)
  и строка, что он считает; в расширенном — список «Модель тока»;
- **слева — параметры**: только поля, нужные модели режима (строка над ними
  говорит, сколько открыто и почему остальные скрыты; у закрытого поля
  подсказка объясняет, почему оно закрыто и где откроется); галочка
  фиксации — только у тех, что подбирает подгонка; внизу всегда видны
  «Рассчитать», «Подогнать к ВАХ», «Заполнить пустые»;
- **в центре — один большой график** с вкладками «ВАХ», «ВФХ и 1/C²»,
  «Плотность тока |J|–V»; под ним — галочки кривых этой модели и строка,
  каких компонент у неё нет и в какой модели они есть; ниже — вкладки
  результатов («Подгонка и отклонения», «Идеальность n», «Предупреждения»,
  «Схема мезы»);
- **справа — как считается модель**: эквивалентная схема (подсказка у
  каждого элемента: что это и почему он здесь), основная формула и расчёт
  одной точки вручную на текущих числах, формула ВФХ.

Режимы:

- **Базовая** — простой диод: I = A·J₀(e^(qV_д/nkT) − 1) + V_д/R_sh,
  V = V_д + I·R_s; поля D, T, n, J₀, R_s, R_sh (для ВАХ) и N_D⁺, N_i, ρ_sub,
  N_As (для ВФХ и V_bi, по Больцману). Утечки и модуляции R_s нет, подгонка
  подбирает только n, J₀, R_s, R_sh. Грубо, но любую точку можно
  посчитать вручную;
- **Расширенная** — модель тока на выбор: однодиодная (6.3), двухдиодная
  (6.3а), физическая (по умолчанию); всё, что измеряется, и вся
  эквивалентная схема (R_s(I), R_sh, нелинейная утечка); граничные условия;
- **Подгонка** — физическая модель и неизмеряемые параметры: подвижности
  неосновных носителей, σ_R, времена жизни, n₂, опции SNS и краевой площади.

**Обучение** («Обучение» на панели, «Справка → Обучение»; само при первом
запуске, отключается переменной `MESA_NO_TUTORIAL=1`): 12 шагов первого
моделирования в базовом режиме на модельном образце с примером ВАХ —
`simulator/tutorial.py`.

Значения при переключении режима сохраняются. «Наборы → Новый образец
(пустые поля)» — начать с пустыми полями. Значение поля меняется колесом
мыши (шаг — десятая часть старшего разряда, с Ctrl — мельче) или вводом с
Enter. У полей, кривых, режимов и строки статуса есть всплывающие подсказки
со ссылкой на пункт методички. Кнопка «Оценить τ₀ по обратной ветви» — в
разделе «Материал и дефекты».
Переключатель **«Тип i-слоя (знак Холла)»**: n — переход i/подложка
(сценарий B), p — переход n⁺/i (сценарий A), «оба» — наложение двух
сценариев с метриками δ_I, δ_C. Подложка — Ge (режим Si — в бэклоге).

**Графики** (вкладки центра): ВАХ — модель и её компоненты (I_диод;
I_01, I_02; I_diff, I_gr — по модели), I_sh, I_L, кривая по n_эксп;
ВФХ и 1/C² — с прямыми на выбранном участке, N из наклона и отсечкой;
|J|–V — полулогарифмически, с J_s(0), прямой по n_эксп и локальным n(V)
на правой оси.

**Коэффициент идеальности n_эксп** определяется из загруженной ВАХ
автоматически (окно V₁…V₂ можно задать вручную) и при загрузке ВАХ
подставляется в n (6.3), J₀ — как I₀/A; дальше их можно менять. Если
n_эксп не определён или недостоверен, блок идеальности показывает причину,
связь с параметрами и что сделать; чаще всего это завышенное R_s — программа
называет предел R_s по наклону dV/dI верха прямой ветви. n_мод — тем
же способом по модели. Строка статуса: V_bi, n_эксп, n_мод и число
предупреждений.

**Наборы образцов** («Наборы» / кнопки вверху): сохранить и загрузить все
параметры, пути к файлам измерений и метаданные в JSON. Опорный образец
(кнопка «Опорный», набор при старте) — модельная структура: D = 500 мкм,
окно кольца 300 мкм, N_D⁺ = 5·10¹⁸, N_i = 5·10¹⁶, N_As = 10¹⁸ см⁻³,
ρ_sub = 50 Ом·см, R_s = 200 Ом (методичка, п. 2.7). Наборы реальных
образцов хранятся в каталоге данных (`MESA_DATA_DIR/samples/<образец>/preset.json`);
набор с `"reference": true`, если он там есть, заменяет модельную структуру.

**Устройство кода** — методичка, гл. 13: запуск, кнопки → функции, порядок
пересчёта `recompute()`, модули. Физическое ядро — пакет `physics/` по
разделам ТЗ (таблица модулей — в `physics/__init__.py`). Модели тока — реестр
`models.py` (эмпирическая (6.3), двухдиодная (6.3а), физическая); своя модель
подключается функцией `parts(s, V_d)` и `register(...)`. Как добавлять и
переписывать физику — методичка, п. 13.9.

**Обогащённый слой подложки и R_s** (с версии 3.5): N_As и d_s задают слой
с повышенной концентрацией Ga у поверхности подложки (ступенька (1.4)); в
сценарии B он — p-сторона перехода. Последовательное сопротивление
оценивается по геометрии мезы и ρ(N) слоёв (6.12)–(6.15) — Справочник,
«Заполнить пустые», проверка R_s подгонки (методичка, пп. 2.6, 9.5).

**Методы дефектов** (панель инструментов или меню «Данные»): ямки
травления (EPD), АСМ и XRD для текущего образца и таблицы образцов;
плотность дислокаций по полуширине кривой качания (7.1), (7.2) [KKA56] с
поправками и пределом чувствительности (7.3); калибровка EPD = c·Xᵏ по
нескольким образцам. Пример таблицы — `examples/defects_example.csv`;
методика — методичка, гл. 14.

**Экспериментальные данные** (кнопки вверху или меню «Данные»): до 5
файлов на график, каждый со своим маркером. Форматы — текст (`.csv`,
`.txt`, `.dat`, `.tsv`) и Excel (`.xlsx`, `.xlsm`; `.xls` — при
установленном `xlrd`). Столбцы V, I (ВАХ) или V, C (ВФХ) в СИ; другие
единицы и порядок столбцов задаются заголовком («I, мА», «C (пФ)»).
Файл разбирает модуль `datafile.py`: при ошибке или подозрительных данных
(перепутаны столбцы, обратный ток по модулю, нет ветви ВАХ, единицы) —
сообщение с причиной, что сделать и ссылкой на методичку; предупреждения
попадают и во вкладку «Предупреждения». Описание формата и примеры —
[`examples/README.md`](examples/README.md), в программе — «Данные → Формат
файлов данных и примеры» (там же «Проверить файл...»).

**Формулы и параметры** (меню «Справка»): вкладка «Параметры подгонки» —
режимы, группы полей и их влияние, граничные условия, табличные значения
и что измеряется; вкладка «Модель» — формулы §0–§7
с источниками, пометками («допущение», «эмпирика», «оценка» …) и
значениями при текущих параметрах; вкладка «Справочник» — уровни Ферми,
вырождение, n_i, L, равновесные концентрации, проверки применимости и
предупреждения.
