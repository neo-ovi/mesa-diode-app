# Формат файлов измерений и примеры

Файл измерения — таблица из двух столбцов: напряжение и измеренная величина.

| Кривая | 1-й столбец | 2-й столбец |
|---|---|---|
| ВАХ | V, вольты | I, амперы |
| ВФХ | V, вольты | C, фарады |

## Форматы

- Текст: `.csv`, `.txt`, `.dat`, `.tsv`. Разделитель столбцов — точка с
  запятой, табуляция, пробелы или запятая. Десятичный знак — точка или
  запятая (запятая — только если столбцы разделены не запятой). Кодировка
  UTF-8 или Windows-1251.
- Excel: `.xlsx`, `.xlsm`. Берётся лист, на котором больше всего числовых
  строк. Формулы допустимы, если файл сохранён в Excel. Старый `.xls`
  читается, только если установлен пакет `xlrd`; иначе сохраните как
  `.xlsx` или CSV.
- `.ods`, `.xlsb`, `.json`, двоичные форматы приборов не поддерживаются —
  экспортируйте в CSV или `.xlsx`.

## Заголовок и единицы

Первая строка может быть заголовком. По нему программа узнаёт столбцы
(«V», «U», «Напряжение»; «I», «Ток»; «C», «Ёмкость») и единицы — в скобках
или через запятую: `I (мА)`, `I, uA`, `C [pF]`.

| Величина | Единицы |
|---|---|
| напряжение | В, мВ (V, mV) |
| ток | А, мА, мкА, нА, пА (A, mA, uA, nA, pA) |
| ёмкость | Ф, мкФ, нФ, пФ, фФ (F, uF, nF, pF, fF) |

Без заголовка значения считаются в СИ (В, А, Ф). Плотность тока (А/см²) не
принимается — нужен ток. Если столбцов больше двух (время, V, I), подпишите
их, иначе берутся первые два.

## Что проверяет программа

При загрузке файл разбирается модулем `mesa_diode/simulator/datafile.py`.
Замечания трёх уровней: **ошибка** (файл не загружен), **проверьте** (данные
загружены, но выглядят подозрительно), **сделано** (что программа поправила
сама). У каждого замечания — что сделать и ссылка на пункт методички
(п. 1А.17).

| Проверка | Уровень | Что делает программа |
|---|---|---|
| формат не поддерживается, файл пустой или двоичный | ошибка | — |
| нет строк с двумя числами | ошибка | — |
| запятая — и разделитель, и десятичный знак | ошибка | — |
| напряжение или величина постоянны | ошибка | — |
| столбцы перепутаны (ВАХ без заголовка) | ошибка | — |
| плотность тока вместо тока | ошибка | — |
| несколько листов Excel с данными | проверьте | берёт лист с наибольшим числом строк |
| больше двух столбцов без заголовка | проверьте | берёт первые два |
| нечисловые строки среди данных | проверьте | пропускает, называет номера строк |
| меньше 20 точек | проверьте | — |
| повторяющиеся напряжения, гистерезис | проверьте | — |
| \|V\| > 100 В, \|I\| > 1 А, C > 1 мкФ | проверьте | подсказывает подписать единицы |
| нет прямой или обратной ветви ВАХ | проверьте | — |
| обратный ток записан по модулю | проверьте | ставит знак «−» при V < 0 |
| знак тока обратный | проверьте | умножает ток на −1 |
| прямой ток меньше обратного | проверьте | — |
| единицы в заголовке | сделано | переводит в СИ |
| точки не по порядку | сделано | сортирует по V |

## Примеры

Синтетические данные — рассчитаны программой по эмпирической модели (6.3)
(n = 1.4, J₀ = 2·10⁻⁶ А/см², D = 500 мкм, R_s = 40 Ом, R_sh = 2·10⁵ Ом,
T = 300 K) с шумом 1 %; реальных измерений в них нет.

| Файл | Что показывает |
|---|---|
| `iv_example.csv` | ВАХ: «;», точка, заголовок с единицами СИ, строка-комментарий |
| `iv_example_decimal_comma.txt` | ВАХ: табуляция, десятичная запятая, ток в мкА |
| `iv_example.xlsx` | ВАХ в Excel: три столбца (время, V, I в мА) — выбор по заголовку |
| `cv_example.csv` | ВФХ: ёмкость в пФ |
| `defects_example.csv` | таблица образцов для окна «Методы дефектов»: EPD, АСМ, RMS, Δω₁/₂ с поправками (шесть условных образцов С-1 … С-6, синтетика) |

В программе: «Справка → Формат файлов данных» — это описание и кнопка
открытия каталога с примерами.
