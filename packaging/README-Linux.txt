Симулятор мезадиода Ge — версия для Linux (3.7-StepByStepLogic)
=================================================================

Устанавливать ничего не нужно: Python, библиотеки и git не нужны, всё уже
внутри программы. Её можно скачать или принести на флешке. Два варианта:
  - архив MesaSimulator-3.7-StepByStepLogic-linux-x86_64.tar.xz — папка
    MesaSimulator
    (рекомендуется: архив меньше, программа запускается быстрее);
  - один файл MesaSimulator-3.7-StepByStepLogic — то же самое одним файлом
    (после скачивания его можно переименовать в MesaSimulator; при каждом запуске
    распаковывается во временную папку, первый запуск дольше).

Где скачать
  https://github.com/neo-ovi/mesa-diode-app/releases/tag/linux-build
  (без входа в GitHub). Сборка обновляется сама после каждого изменения ветки
  CV-VI-Linux; сейчас в ней код версии 3.7 (ветка CV-VI-ver.3.7-StepByStepLogic).

Что внутри для проверки
  Всё, чтобы проверить программу целиком: модельный образец (открывается
  при запуске), обучение с примером ВАХ, примеры файлов измерений CSV, TXT и
  Excel («Данные → Формат файлов данных → Открыть каталог примеров»),
  таблица примера для окна «Методы дефектов». Всё это — выдуманные данные.
  Наборов реальных образцов и методички в этой сборке нет: они только в
  приватном репозитории (раздел «Данные образцов и методичка» ниже).

Где работает
  Linux Mint 21.x и 22.x (Cinnamon, MATE, Xfce), LMDE 6 и 7,
  Ubuntu 22.04 и новее, Debian 12 и новее; обычный ПК или ноутбук (x86-64).
  На Linux Mint 20 и старше не запустится: там слишком старая системная
  библиотека glibc (Mint 20 уже не поддерживается).

Как запустить
  1. Архив распакуйте в домашнюю папку (правой кнопкой → «Извлечь сюда»),
     например в папку ~/Программы. С флешки тоже сначала скопируйте в
     домашнюю папку: флешки (FAT32, exFAT) не хранят признак «исполняемый»,
     и прямо с них программа может не запуститься.
  2. Откройте папку MesaSimulator и запустите файл MesaSimulator двойным
     щелчком. Папку _internal рядом с ним не трогайте и не разделяйте с
     файлом: в ней Python и библиотеки программы.
  3. Если двойной щелчок не запускает файл: правой кнопкой → «Свойства» →
     «Права» → отметить «Разрешить выполнение файла как программы».
     То же в терминале:  chmod +x ~/Программы/MesaSimulator/MesaSimulator
     (у одного файла, скачанного браузером, это нужно всегда).
  4. Первый запуск — несколько секунд дольше: программа один раз собирает
     список шрифтов. Чтобы программа была в меню приложений: в программе
     «Настройки → Добавить в меню приложений».

Данные образцов и методичка
  Программа работает и без них — на модельном образце. Наборы образцов и
  методичка лежат в приватном репозитории данных (папки samples и docs).
  Git для этого не нужен: скачайте репозиторий архивом (на GitHub —
  «Code → Download ZIP») или перенесите папку на флешке, распакуйте в
  домашнюю папку и укажите её в программе: «Настройки → Папка с данными».

Если что-то не так
  - Проверка без окна (в терминале, в папке с программой):
        ./MesaSimulator --check
    Покажет систему, шрифты, масштаб, папку с данными и проверит расчёт
    и чтение файлов измерений.
  - Ошибки программы записываются в ~/.mesa_diode/errors.log.
  - Слишком мелко или крупно: «Настройки → Масштаб интерфейса» (по умолчанию
    «Авто» — как в настройках рабочего стола). Разово:
        MESA_UI_SCALE=1.25 ./MesaSimulator
  - «Нет графического сеанса»: запускайте из рабочего стола, а не из
    текстовой консоли.
  - Один файл не запускается, если временная папка /tmp смонтирована с
    запретом запуска (редко):  TMPDIR=$HOME/.cache ./MesaSimulator
  - Настройки программы — в папке ~/.mesa_diode (её можно удалить: всё
    вернётся к значениям по умолчанию).

Удаление
  Удалите папку (или файл) MesaSimulator и папки ~/.mesa_diode и
  ~/.cache/mesa-simulator. Пункт меню: «Настройки → Добавить в меню
  приложений → Нет» или удалите ~/.local/share/applications/mesa-simulator.desktop.
